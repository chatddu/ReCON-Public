# ReCON-Public
Publicly available models, python code, json files, and other components for developing, facilitating, playing, and continually improving ReCON* and its flagship playing piece, intqoin.  Visit https://chatddu.com for the full context.

This code falls far short in the use of contemporary coding conventions, has been incrementally changed over several years with little to no refactoring, and generally needs a complete restart in terms of architecture, design, and development.  Despite all of that, the author is satisfied with the degree to which this code has satisfied their requirements and hopes it provides inspiration for its gamification as the basis for encouraging the ongoing healing of social divisions.
